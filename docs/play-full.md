# 风过玉米地 · 完整场景首版

Windows 双击项目根目录 **`Start-Full-Scene.cmd`**。启动器使用本机 Godot，先导入资产再打开完整场景。此交付为可运行的项目及启动器，尚不是独立发行安装包。

旧版保留：`Start-Adventure.cmd` 打开入口教学 M1；`Start-Validation.cmd` 打开 M0 模型、动画与窗口按键验证。

## 操作

| 操作 | 按键 |
|---|---|
| 移动 / 奔跑 | WASD 或方向键 / Shift |
| 树枝挥击 / 解锁后的玉米单发 | 空格或鼠标左键 |
| 拾取、清理、开闸、移车、组合道具；矮栏附近翻越 | E |
| 投石引开巡游怪 | F |
| 玉米枪解锁后切换树枝 / 枪 | Q |
| 玉米枪蓄力散射 | 按住鼠标右键，松开发射 |
| 晴天 → 雨天 → 雪天 | F6；也可在暂停菜单选择 |
| 白天 / 夜晚 | Tab |
| 暂停 / 继续 | Esc |
| 从头重试 | R |

默认是夏日晴天。雪天作为季节效果预览；切换天气不改变已经完成的谜题。

## 这次的路线

入口查看小鸡并找回弹珠铁盒，向北清理水渠堵塞，再操作闸门。水流恢复后穿过高密玉米，观察巡游怪造成的晃动，可投石引开、绕行或利用矮栏脱身。到农具棚附近捡木板，垫好板车轮子后移车，进入棚里取得旧发射器。

最后进入稻草人所在空地。先用树枝抓住攻击空档；Boss 半血撞出玉米后，按提示组合玉米枪，当场练习单发和近距蓄力散射。胜败均可重试。

## 明早检查建议

1. 出生点按 F6 比较三种天气，再按 Tab 比较夜晚效果。
2. 按屏幕任务提示走一次五区流程，留意第一次不知道该往哪走的位置。
3. 在巡游怪和 Boss 处观察动作预警，分别试绕行、近战和玉米枪。
4. 测一次暂停、失败重试和胜利重试；确认重试后谜题与天气恢复初始状态。

## 制作与验证范围

主角沿用正式模型，动画按 Meshy 库选择 → Blender 裁剪与调整 → Godot 接入；除原来的待机、走、跑、树枝攻击外，追加受伤、拾取、交互、推车和翻越。推车与翻越仍是原型动作，手部接触和位移同步需要继续打磨。

农具棚、板车和树干已通过本次真实 Meshy API 任务生产，保存了独立参考图、原始模型和 Blender 母版。树模型生成时缺失树冠，使用 Blender 补建叶簇；棚屋拆出屋顶以便进入后隐藏。三件模型与五段新增动作本批共消耗 105 积分，提交后余额 1153，详见[生产记录](../art/environment/meshy/production-ledger.md)。

地形、天气、玉米组合和部分小道具仍由程序搭建；怪物、Boss、玉米枪仍是首版外形。整体美术尚未达到概念图完成度，地面细节、树叶层次、环境小物和敌人需要继续统一。完整关卡功能与环境效果以最终 [QA 记录](qa/full-scene-results.md) 为准。首次真人游玩时长、战斗难度和声音听感需要实际试玩校准；不会用自动熟知路线的耗时替代 20～30 分钟目标验证。
