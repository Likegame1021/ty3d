# 下一阶段建议：入口教学区可玩闭环

状态：用户已同意并要求“继续干”，正在执行。详细坐标、职责与接口见[入口教学区制作规格](entry-milestone-spec.md)。此前首个样件已完成出图→Meshy→Blender→Godot技术链路与基础操作验证；用户已反馈窗口按键实测无问题。

## 本轮要回答的问题

玩家能否在固定斜俯视镜头下，读懂“看不清，但能感觉到”的玉米动静，并独立完成一段3～5分钟的小冒险。

## 建议体验流程

入口 → 看到第一次玉米晃动 → 发现无害小动物 → 根据第二条动静找到隐藏收集物 → 遭遇一个巡游敌人并绕开或击退 → 到达出口，显示完成结果。

小动物和敌人先用可辨认简模，敌人造型仍属原设计暂定方向。第一轮只有一个收集目标、一段短路程和一次敌对遭遇，复用现有男孩、树枝、植被与道具。

## 交付分工

| 职责 | 交付 |
| --- | --- |
| 主策划 / 关卡设计 | 入口路线、玉米疏密、视线安排、每步引导、出口条件 |
| 主程序 | 收集交互、巡逻和短距追逐、受击反馈、失败重置、完成判定 |
| 技术美术 / 特效 / 音效 | 风与生物扰动的差异、声源方向、遮挡下的主角辨识、命中反馈 |
| 主美 / 角色资产 | 先检查现有主角大小与配色；玩法可读后确定新增生物资产需求 |
| QA | 首次游玩路线、提示理解、失败重试、穿墙/卡死、完成状态可重复性 |

## 开工顺序

1. 用当前样件调整镜头和地块，完成入口路线与出口，不生成新模型。
2. 增加隐藏动静源、收集物与最小敌对行为，使完整流程能走通。
3. 根据运行画面调整波纹、声音、遮挡与引导；记录误判发生的位置。
4. 试玩验收后确定需要精做的生物和动作，再进入新增资产生产。

## 通过标准

- 玩家不依赖旁人讲解，知道如何开始、找东西并到达出口。
- 能发现至少一次无害动静，理解玉米动不必然代表敌人。
- 敌人被玉米遮挡时仍能依靠动静作出一次正确判断。
- 收集、遭遇、完成和重试均能重复运行，没有必须靠重启修复的卡死。

水渠谜题、高密玉米追逐、农具棚与Boss在后续逐区制作；本建议不改变原20～30分钟五区设计。
