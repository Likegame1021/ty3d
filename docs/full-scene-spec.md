# M2 完整玉米地与天气 · 执行规格

2026-09-28。用户在 M1 验证通过后明确授权：加入雨雪天气，直接制作完整场景，无需等待逐项确认。后续明确新增美术要走出图→Meshy→Blender→Godot，动画从 Meshy 库选择再 Blender 微调，并强调检查美术风格。沿用既定美术和五区关卡设计。M2 是完整可玩的场景首版，正式美术精修和首次游玩 20～30 分钟节奏不冒称已验收。

## 场景与流程

世界范围 x=-28～28、z=-48～48，地面 y=0。出生 (0,0.05,40)，固定斜俯视镜头跟随。五区从南向北：入口中心 (0,34)、水渠 z=19、高密玉米中心 (-8,4)、农具区 (16,-15)、Boss 中心 (0,-34)。主路用宽土路和连续路标相连，可见地标区别各区。

1. 入口小鸡教学，找回弹珠铁盒；由玉米动静发现无害小动物。
2. 水口 (0,22) 清理堵塞，再到闸门 (5,20) 开闸；水流、湿地、倒伏玉米可见，开放北行通路，不能从水渠两侧跳过任务。
3. 高密区实际巡游怪引起玉米晃动；石头引怪、矮栅栏翻越至少有可操作的原型，追逐可摆脱。
4. 农具区捡木板 (12,-9)，垫轮/移动板车 (16,-13)，进入棚内取得旧发射器 (17,-18)。
5. 进入圆形 Boss 场。荒田稻草人拥有扫击、钻入玉米/移动预警/冲出、召唤 2～3 小怪。约半血撞坏玉米储存物，现场 E 组合玉米枪。单发中距、按住蓄力释放近距散射。击败 Boss 后明确完成，可以重试。

受伤、无敌帧、失败、重试、暂停和暂停 UI 防穿透输入都需有效。状态机防止乱序交互、重复领取和 Boss 前跳过必需物品。M0/M1 入口保留回归。

## 天气

晴、雨、雪三态，F6 循环，Tab 日夜独立；暂停界面提供天气选择。雪作为季节预览，默认夏日晴天。雨丝、地面湿润/水洼涟漪、雪花和积雪表面、天气光照、低音量环境声。兼容当前 OpenGL Compatibility 渲染；控制粒子范围和数量。天气不遮挡任务文字、不更改过关条件，暂停冻结，重试恢复晴天。

## 模块契约与责任

- 主程序：`levels/full.tscn`、`levels/full.gd`、`scripts/full_*`、`ui/full_hud.gd`、`tests/test_full*`；唯一负责共享 player.gd 的可配置边界。根负责入口、配置、最终集成测试。
- TA/场景：`environment/full_field.gd`、`environment/weather.gd`、`environment/full_*`、`environment/weather_*` 及其检查脚本；不改 M0/M1 环境。动态模块均采用米为单位。
- 场景接口：`set_player_position(Vector3)`、`set_night(bool)`、`set_weather(String)`（sunny/rain/snow）、`set_progress(Dictionary)`、`set_actor_sources(Array[Vector3])`、`reset_field()`。字段 progress: canal_open, cart_moved, launcher_taken, boss_active, corn_spilled, boss_defeated。
- 场景负责水渠屏障、闸门/板车视觉；玩法负责交互目标和实体敌人。交互坐标以本规格为准。
- QA：独立验收、代码审查和截图审查，结果写 `docs/qa/full-scene-results.md`，不改产品代码。
