# 玉米枪专项试玩

更新：2026-09-28。Windows / Godot 4.7.2。

双击项目根目录 `Start-Corn-Gun.cmd`。无需重走主线，进入后即装备玉米枪。首启会导入资源。

## 操作

| 输入 | 行为 |
| --- | --- |
| WASD / Shift | 移动 / 跑动，持枪时可边走边瞄准 |
| 鼠标移动 | 瞄准；对准敌人身体或木靶靶心即可 |
| 按住左键 | 持续发射玉米粒，松开停止 |
| 按住右键再松开 | 约 0.55 秒蓄满，释放近距离扇形散射；未蓄满为普通弹 |
| Q | 玉米枪 / 树枝剑 |
| F | 木靶 → 三波清怪 → 稻草人 → 木靶 |
| E | 在木靶模式复原所有靶子 |
| R | 清空当前挑战，恢复体力并回到木靶 |
| Esc | 暂停 / 继续 |
| Tab / F6 | 昼夜 / 晴雨雪切换 |

试枪场采用无限弹药，便于反复比较连射、蓄力、移动与命中反馈。菜单点击不会透传射击；暂停、失焦、切换武器、胜负和重开会取消正在进行的射击输入。

## 枪的表现

- 金黄色玉米粒枪身、绿色苞叶、绳绑和木制握把；双臂托举，保留走跑和交互动画。
- 普通射击：约 7 发/秒，单目标 1 点伤害，射程 9 个场景单位；近处目标与实体墙会阻挡射击。
- 蓄力散射：约 0.55 秒蓄满，前方 60° 扇面、射程 5.5 个场景单位；每个有效目标受到一次 3 点伤害，七条粒子弹道表现散射。
- 枪口闪光、苞叶抖动、后坐与轻微镜头震动；玉米粒拖尾、命中爆粒、伤害数字和准星命中提示。
- 枪口聚拢亮粒、准星圆环和 HUD 蓄力条共同表示蓄力；射击、散射、命中和蓄力使用独立层次的声音反馈。

木靶体力 24，打倒后自动复原。清怪模式为 4 / 6 / 8 只田鼠，下一波出现前留短暂间隔，出生点与玩家保持距离。稻草人模式有 36 点体力，保留横扫、钻地与召唤。

## 接入原关卡

`Start-Full-Scene.cmd` 仍进入原完整玉米地流程，在稻草人战中组合玉米枪后，获得同一套射击、瞄准、持枪与特效。树枝仍然是近战剑。

本次完成的是玉米枪及其试射入口，尚未接入肉鸽选路、材料掉落、武器改装或武器升级树。枪模型与特效为程序化制作；角色沿用项目现有模型，射击姿态由双臂骨骼修饰器实现。
