# 美术风格检查基线

用户于2026-09-28再次强调检查美术风格。本页约束后续参考图、Meshy模型和Godot实机验收。

主要风格标尺：`docs/references/henan_countryside_forever_summer.png`；主角以既定红围巾、旧白T恤、蓝短裤的正式模型为准。

- 温暖河南乡村童年、3D模型与固定斜俯视；风格化卡通写实，使用厚实明确的大块形体和清晰轮廓。
- 土黄、暖木褐、自然绿为环境基础色。材质表现适度磨损与生活痕迹，避免照片级密集裂纹/污渍，也避免纯色方块替代所有材质细节。
- 树冠必须符合夏季茂盛形态，以有体积的叶簇为主。Meshy生成出裸枝不能因任务状态SUCCEEDED而通过。
- 多视角检查棚屋开口、板车轮/把手、树冠厚度；重要轮廓不能粘连或缺失。尺寸与1.2m主角以及独立游戏碰撞匹配。
- 雪天保留地面层次与路面可读性，雨天材质避免金属/镜面感，夜晚保留暖灯地标。天气不能破坏角色识别。
- 导入Godot后在正式镜头距离检查缩小后的轮廓和纹理，至少比较晴天与雨雪；参考图通过不能替代实机检查。
