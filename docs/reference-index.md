## 资料优先关系

1. 用户后续明确修订的文字设定。
2. 当前统一设计档案 v1 的已确定内容。
3. 对应用途的参考图：五区结构优先 REF-07；资产集合优先 REF-03；角色外观优先 REF-08。
4. 其他参考图作为氛围与局部设计补充。

## 已识别的旧内容与缺项

- REF-08 下方的像素行走动画属于旧方向，不用于当前 3D 制作方案。
- REF-08 为合并角色设计板，不能当作本次已经提供了四张独立 T-Pose 图片。
- 角色板约 110 cm、资产板植株高度等为图示；角色身高按正文 1.1～1.3 m，整体尺寸留待 Godot 中统一。
- REF-07 的分支箭头是布局示意；关卡流程仍需先取得旧发射器，才衔接 Boss 战中的玉米枪组装。
- 图上游戏标题、小刀、额外怪物、瞭望台、出口和收集道具等，不自动变为文字 v1 已确认范围。
- 主村概念图中的街景视角用于美术气氛参考，正式游戏仍采用固定斜俯视。

## 使用方式

环境概念板适合确定风格与拆分资产。正式建模沿用用户的“独立资产参考图 → Meshy / Tripo → 修整 → GLB → Godot”流程；主角四向独立参考图待补入本目录后再更新索引。
