## 1. 当前游戏美术方向

**3D 模型 + 2.5D 固定斜俯视视角 + 风格化卡通写实 + 河南农村童年感。**

已经放弃纯像素风。镜头和场景阅读方式参考《逃离鸭科夫》这一类俯视 3D 游戏，整体氛围为：

- 温暖阳光，90～00 年代河南乡村童年气质。
- 较高饱和但自然的颜色。
- 简化但明确的几何形体，清楚的轮廓。
- 模块化，方便 AI 建模与场景组合。
- 白天治愈，夜晚神秘危险；不做恐怖游戏。

建筑、树木、院墙、农具等优先设计成便于 Tripo / Meshy 识别和建模的独立模块。

总体美术参考：REF-06、REF-09、REF-10。玉米地场景氛围参考：REF-01、REF-02、REF-04、REF-05。

## 2. 主角基础设定

主角是一个 **8～10 岁左右，在河南农村长大的普通男孩**。

性格：调皮、爱闯祸、胆大、好奇、爱到处乱钻，对任何奇怪东西都想过去看看。

角色定位不是“小英雄”，而是“一个觉得村里哪里都很好玩的普通小孩”。

## 3. 主角视觉特征与比例

| 部位 | 已确定方向 |
| --- | --- |
| 头部 | 黑色凌乱短发；大块头发轮廓，俯视角容易辨认；大眼睛，偏圆的脸 |
| 上衣 | 米白 / 旧白色 T 恤，有泥点与使用痕迹，避免干净现代儿童服装感 |
| 标志元素 | 红色小围巾、斜挎旧帆布包，承担远距离辨识度 |
| 下装 | 蓝色旧短裤，有补丁、明显缝线与磨损 |
| 鞋袜 | 蓝色旧球鞋、白袜，鞋有泥土与磨损 |
| 比例 | 身高约 1.1～1.3 m；头稍大，手脚略大，身体轮廓简单，俯视动作清楚 |

整体原则：不是刻意表现“穷、脏、破”，而是一个每天在村里跑来跑去、衣服永远不可能特别干净的小孩。

最终进 Godot 时再统一角色与场景比例。参考图中的“约 110 cm”作为示意，不取代正文的身高范围。

## 7. 玉米地定位与核心体验

玉米地是 **第一块正式冒险关卡**，预计首次体验 **20～30 分钟**。

主要类型：**探索解谜 + 环境观察 + 轻战斗 + 追逐 + 小 Boss**。

不是纯迷宫、纯打怪或传统机关神庙。

核心体验：**“看不清，但能感觉到。”**

玉米高于主角。玩家经常无法直接看见敌人，需要结合玉米晃动、沙沙声、倒伏方向、地面脚印和被拨开的玉米，判断有什么正在移动。

| 移动单位 | 玉米波动的视觉语言 |
| --- | --- |
| 小动物 | 轻微、快速 |
| 普通怪物 | 明显的移动轨迹 |
| 大型敌人 | 大片玉米剧烈晃动 |

## 8. 玉米地五区结构

正式关卡结构参考 REF-07；其他概念板中的旧小地图用于氛围与局部构图参考。

### ① 入口教学区

玉米较稀，教学重点是观察玉米晃动、基础移动、树枝攻击、小怪战斗与视线遮挡。

第一场“沙沙声”可以只是鸡或兔子，建立“玉米动 ≠ 一定是敌人”的认知。

### ② 水渠解谜区

主要谜题：**恢复水渠**。

环境包含堵塞的水口、泥巴、木头、杂草与手动闸门。

解谜链条：

> 清理堵塞 → 打开闸门 → 水流恢复 → 土地被浸湿 → 一部分玉米倒伏 → 出现原本隐藏的道路。

谜题来自农村生活环境的游戏化，不采用凭空出现的魔法机关。

### ③ 高密玉米区

本关核心区域：玉米非常高、视野很差、路线不完全明确，敌人在玉米行间移动。

- **观察**：判断玉米波纹。
- **躲藏**：利用草垛、板车、小空地和木栅栏。
- **引怪**：扔石头制造声音。
- **追逐**：第一次出现较强敌人；玩家可以翻越矮栅栏，怪物需要绕路。

这一段开始教玩家：**地形本身就是战斗工具。**

### ④ 废弃农具区

比较开阔的喘息区域，以探索、小谜题、收集为主。

主要元素：废弃农棚、板车、草垛、木箱、木桶、农具、稻草人。

农具棚谜题：

> 板车挡住棚门 → 玩家找到木板 → 垫轮子 / 移动板车 → 打开农具棚。

棚内获得 **旧发射器**，为后续玉米枪解锁作铺垫。

### ⑤ Boss 区

中心是一块明显空地，中间为巨大旧稻草人。

Boss 名称：**荒田稻草人**。

视觉由麻袋、稻草、木杆、草帽构成，遵循农田幻想风，避免恐怖造型。

## 9. 荒田稻草人机制

Boss 只需要三个主要能力：

| 能力 | 行为与玩法作用 |
| --- | --- |
| 扫击 | 近距离攻击 |
| 钻入玉米 | Boss 消失，玩家通过玉米移动轨迹判断冲出方向，是整关观察玉米的最终考试 |
| 召唤小怪 | 召唤 2～3 只，主要制造压力 |

## 10. 玉米枪解锁与基础设计

Boss **约 50% 血量**进入第二阶段：

> Boss 撞坏储存玉米的设施 → 大量玉米掉出 → 之前拿到的旧发射器与玉米组合 → 现场解锁玉米枪 Lv.1 → 立即在 Boss 战中使用。

奖励发生在战斗过程中，不作为击败 Boss 后才出现的菜单奖励。

| 攻击 | 已确定方向 |
| --- | --- |
| 普通攻击 | 高速发射玉米粒；中距离、单发、射速较快，比树枝安全 |
| 蓄力攻击 | 一次喷出多颗玉米粒，类似近距离散射 |

定位概括：**单发 = 中远距离；蓄力 = 近距离爆发。** 具体射程、射速、伤害、蓄力时间未在 v1 中设定数值。

## 11. 玉米地白天 / 夜晚

| 白天 | 夜晚 |
| --- | --- |
| 探索、解谜、收集、NPC、找路、少量敌人 | 敌人更多、视线更差、稀有素材、特殊怪物 |
| 温暖、治愈 | 神秘危险，玉米晃动更具威胁，环境照明成为机制 |

不是“白天能来、晚上不能来”。目标是通关后仍值得返回探索。

## 13. 玉米地敌对生物方向

以下按用户原文记录为**目前暂定方向**：

- 基础怪物：田鼠 / 农田异常生物。
- 高密区敌人：**玉米巡游怪**，玩家经常只能通过玉米晃动发现它。
- Boss：**荒田稻草人**，关卡机制见上文。

整体原则：奇怪、有冒险感，但不恐怖。

概念板中出现的野狗、乌鸦、藤蔓怪、玉米虫等没有全部被正文确认为敌人名单；它们保留为视觉候选。
