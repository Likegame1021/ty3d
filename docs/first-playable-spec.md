# 首个可运行验证样件：范围与团队

2026-09-27。用户明确要求组织专职角色并直接制作可运行首个验证样件。目标平台：Windows 电脑。

## 目标

交付能在本机启动的 Godot 样件：8～10 岁河南乡村男孩，树枝，固定斜俯视，小块玉米地。跑通参考图 → Meshy 模型与绑定 → Blender 母版与交付 → Godot 操作与交互。

首轮必须验证走、跑、待机、树枝攻击、碰撞、命中反馈、玉米风摆与移动扰动、日夜可读性、GLB 导入。完整水渠、Boss、玉米枪与完整20～30分钟关卡不在首样件范围。

## 软件与坐标约定

- 已实测：Blender 5.2.2 LTS，`D:/blender.exe`。
- 已实测：Godot 4.7.2 stable，`C:/Users/21078/Downloads/Godot_v4.7.2-stable_win64.exe/Godot_v4.7.2-stable_win64_console.exe`。
- 工程位于 `game/`。使用 GDScript，Compatibility 渲染器，1280×800初始窗口，支持缩放。
- 1单位=1m；角色样件按1.2m验收。Y轴向上；角色视觉+Z朝前。
- 角色交付固定路径：`game/assets/characters/boy/boy.glb`。动画名：`idle`、`walk`、`run`、`attack_branch`。
- 角色骨架命名从实际导入资源读取；右手挂点需验证，不猜测成功。动画可按名称别名寻找，主代理会提供最终动画清单。
- 环境地图核心范围 X=-14..14、Z=-16..16；出生点(0,0,8)。中心道路沿Z轴，保证可以从出生点到(0,0,-5)练习目标。

## 操作与玩法接口

- WASD / 方向键移动，Shift跑，鼠标左键 / Space挥树枝。
- E在交互距离内与目标交互；Tab切换日夜预览；R重置位置与练习目标；Esc显示暂停 / 返回操作提示。
- 角色走速2.4m/s，跑速4.6m/s。胶囊碰撞体约半径0.22m、高1.2m。脚部着地。
- 摄像机固定斜俯视（不允许自由旋转），正交，轻柔跟随玩家；角度和可视范围根据实际画面调整。
- 练习目标是无敌意的稻草练习桩，占位/简化形态允许用于目标；命中显示晃动、短促打击反馈与命中计数，无血腥。
- 单次攻击只命中一次。暂停期间不能继续造成命中；重置可重复验证。
- 首版不做完整敌人AI。玉米地里一个简易移动扰动源用于观察波纹，明确作为验证演示。

## 文件所有权和环境接口

主程序拥有 `game/project.godot`、`game/main.tscn`、`game/scripts/`、`game/ui/`、`game/tests/`；可创建程序所需场景但不编辑 `game/environment/` 或 `game/assets/`。

技术美术拥有 `game/environment/`、`game/assets/environment/`、`art/environment/`、`tools/build_environment.py`；不修改 project.godot、main.tscn、角色资产或主程序文件。

主代理拥有 `art/characters/`、`game/assets/characters/`、`tools/meshy/`、`tools/characters/`、根目录启动脚本、项目文档与最终发布。QA拥有 `docs/qa/` 和 `tools/qa/`。

环境入口 `game/environment/cornfield.gd`：继承Node3D，公开 `set_night(enabled: bool)`、`set_player_position(world_position: Vector3)`；`_ready()`建立自身环境。主程序在main场景实例化此脚本；每帧传入玩家位置。碰撞地面由环境负责。小区域内可见玉米扰动由环境负责。

环境使用层1碰撞；玩家层2；练习目标可用独立Area3D/组识别，攻击不依赖环境的节点名称。玩家命中练习桩由主程序负责，环境不另外生成重复目标。

## 完成条件

1. 项目可用Godot启动，且尽可能提供Windows可执行版和启动说明。
2. 正式角色模型来自本轮参考图与Meshy流程，保留Blender母版；若任一步失败，明确列出，不能把临时几何替身当成全流程成功。

6. Headless解析/基本行为检查通过，并取得实际渲染截图；没有未处理脚本错误。
7. 原始结果、任务记录、母版、交付模型与验收记录在本地保存。
