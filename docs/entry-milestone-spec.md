# M1 入口教学区：制作规格

用户已同意下一阶段建议并明确要求“继续干”。在现有Godot工程实现一段目标3～5分钟的入口教学冒险；目标时长需要首次试玩校准，不靠强制等待凑时长。

## 体验与完成条件

入口接到找回弹珠铁盒的小目标 → 观察玉米沙沙动静并发现无害小鸡 → 跟随另一处环境线索进入侧边玉米找到铁盒，按E拾取 → 遭遇一个田鼠型巡游怪，可绕开或用树枝击退 → 带铁盒到出口完成。

无害小鸡不会受伤，也不产生奖励刷取。鼠怪使用有辨识度的简模，玩法通过后才考虑Meshy正式资产。本轮不调用收费生成接口。

三格体力，敌人接触攻击有可读前摇、冷却与受伤无敌时间；失去体力显示失败并允许重试。完成状态冻结危险，显示结果与重新开始按钮。R、暂停后重试均完整重置任务、动物、怪物、物品、体力、攻击和时间。物品只能收集一次，出口未满足条件需说明缺什么。

## 关卡坐标与接口

核心边界仍X±14、Z±16。出生(0,0,12)，小鸡起点(-3.8,0,7)，隐藏物品(-5.5,0,1)，鼠怪巡逻中心(-1.8,0,-6)，出口(0,0,-13)。中央道路与侧边物品路径保证可达；最终位置可由程序/关卡直接沟通小范围调整。

保留M0：`game/main.tscn`及原脚本/测试作为独立技术验证。M1新增入口`game/levels/entry.tscn`，场景主逻辑`game/levels/entry.gd`。复用真实主角GLB与四动画，保持M0回归。

关卡环境入口 `game/environment/entry_field.gd` 继承Node3D，可在内部复用/继承cornfield。API：

- `set_night(enabled: bool)`。
- `set_player_position(world_position: Vector3)`。
- `set_story_sources(chicken_position: Vector3, creature_position: Vector3, creature_active: bool)`：以实际动物和怪物位置驱动玉米，不再播放无关自动巡游波纹。可将无效源放到(1000,0,1000)。
- `set_story_stage(stage: int)`：0观察动静、1找铁盒、2去出口、3完成/失败；环境可以据此管理隐约提示与声音。
- `reset_story()`：复位环境时钟/音效。环境不生成重复玩家、敌人、物品或完成判定。

声音尽量程序生成简短自然沙沙/鸡叫提示，使用AudioStreamPlayer3D；无音频设备时仍能游玩。声音属于辅助提示，晃动和路径同样有效。主角遮挡处理限局部，保持稠密玉米体验。

## 文件责任

主程序代理：新增 `game/levels/`、`game/scripts/entry_*`、`game/ui/entry_*`、`game/tests/test_entry*`和`render_entry.gd`；可最小修改共享player/target（需兼容M0），不修改GLB、环境脚本、project.godot或根启动器。

关卡/技术美术代理：`game/environment/entry_*`、必要的独立shader/音效与`game/assets/environment/entry_*`；优先复用现有模块；需要改共享cornfield时先保持默认M0行为并通知主程序。负责入口路径/指示物/出口视觉和实际源驱动玉米，不写角色和任务逻辑。

QA代理：`docs/qa/entry-*`与`tools/qa/entry-*`，独立验收与报告；不改产品实现。主代理负责规格、入口配置、启动器、集成验证、最终截图及文档。

## 测试与验收

- 完整路线包含小鸡揭示、拾取、敌对遭遇、出口完成；未拾取无法完成，重复拾取不重复计数。
- 至少验证一条不击杀敌人的完成路线；敌人有边界和脱战/回归机制，不追到出生区无限攻击。
- 树枝单挥对同一目标只造成一次命中；怪物受击/击退，无血腥。
- 失败、胜利、暂停、继续、R重试不会残留旧状态/重复计数/按钮点击穿透攻击。
- 共享主角四动画、M0原测试继续通过；真实渲染检查入口、线索、危险、完成画面和960×600 HUD。
- 自动化测试可用输入事件或可解释的场景状态设置；报告区分自动验证、GPU画面检查和用户真实试玩。
- 本阶段不用Computer Use操纵桌面，截图走Godot渲染脚本，避免抢用户鼠标键盘。
